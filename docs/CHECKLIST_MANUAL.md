# Lista de comprobación manual

Ejecutar estos flujos con una cuenta de prueba y el emulador de Firebase antes
de publicar cambios. No usar datos de producción durante las pruebas.

- [ ] Crear una cuenta y confirmar el correo.
- [ ] Asignar el claim `admin` a una cuenta de prueba con
      `scripts/set-admin-claims.mjs` y pedirle que cierre sesión y vuelva a
      ingresar.
- [ ] Iniciar y cerrar sesión.
- [ ] Solicitar el restablecimiento de contraseña.
- [ ] Publicar un producto sin fotos y otro con fotos.
- [ ] Aprobar una publicación como administrador.
- [ ] Destacar una publicación y quitar el destacado.
- [ ] Verificar y dejar de verificar a un vendedor.
- [ ] Probar filtros, búsqueda y orden por precio.
- [ ] Guardar y quitar favoritos.
- [ ] Crear y borrar una publicación de «Se busca».
- [ ] Crear una opinión y borrarla como administrador.
- [ ] Enviar y resolver una denuncia como administrador.
- [ ] Probar cada opción del panel de accesibilidad y restaurar los valores normales.
- [ ] Abrir el enlace de WhatsApp de una publicación y el de auspiciantes.
